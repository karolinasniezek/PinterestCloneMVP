# Pinterest Clone

A Pinterest-inspired Single Page Application built with React, TypeScript and Vite.

## Features

- Display pins
- Search pins
- Add new pins
- Edit pins
- Delete pins
- Favorite pins
- Local Storage persistence

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Status

MVP (Minimum Viable Product)

This project includes the core functionality of a Pinterest-style application and will be expanded with additional features.

## Future Improvements

- Boards support
- Pin categories
- User authentication
- Backend integration
- Cloud image storage
- Improved responsive design

## Getting Started

```bash
npm install
npm run dev
```
